Where oh-my-mermaid runs and how its running parts connect. omm is a command-line tool, not a hosted service: it is published from GitHub (and, after the first release, to npm), installed on a developer's machine, and runs there as a Node.js process. The AI coding tools call it through their omm skills, it reads and writes the project's `.omm/` folder, and `omm view` serves the diagrams to the browser on 127.0.0.1:3000. The cloud API is only used when OMM_API_URL is set.
